# NUKKIKKI 🐵🎨

이미지 누끼(배경 제거) 일괄 처리 프로그램

## 다운로드

**[👉 최신 버전 다운로드](https://github.com/LTLT1008/NUKKIKKI/releases/latest)** 페이지에서 아래 **Assets** 항목의 `NUKKIKKI.exe` 클릭

## 사용법

1. `NUKKIKKI.exe` 실행
   - 처음 열 때 Windows 보안 경고가 뜨면 **"추가 정보" → "실행"** 클릭
   - 창이 뜨기까지 5~10초 걸립니다
2. 이미지를 창 가운데로 **드래그**하거나, 오른쪽 위 **폴더 선택**으로 폴더째 추가
3. 출력 크기 선택: 400x400 / 800x800 / 1200x630 / 1920x1080
4. **실행** 클릭
   - 최초 1회만 AI 모델 자동 다운로드(350MB)가 진행됩니다 — 인터넷 연결 필요
5. 완성된 누끼 이미지(투명 배경 webp)는 **다운로드 폴더**에 저장됩니다
   - 왼쪽 위 ⚙ 설정에서 저장 위치 변경 가능

## 요구 사항

- Windows 10/11 (64비트)
- 첫 실행 시에만 인터넷 연결 필요
